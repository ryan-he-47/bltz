## 2. 补充调研的新发现(vs docs/13-16 的既有裁决)

### 2.1 加重项:Fast BLT 已被 ICML 2026 接收

检索命中报道称 Fast BLT(2605.08044)被 ICML 2026 接收(作者 Julie Kallini 的
公开祝贺帖,经聚合站转引,**未一手核实接收列表**)。若属实,含义明确:

- "层级骨干 × 并行字节解码"这个交叉点**不是预印本荒野,而是主会占位**;
- 直接邻居有了顶会背书 + 1B/3B 规模 + Meta/Stanford/UW 阵容,审稿人将以它为
  锚点审任何后到的并行字节解码工作;
- bltz 若写架构论文,Related Work 的最低配置 = Fast BLT(ICML 2026)+ DMBP
  + MTPC(ICML 2026,带开源代码,见 docs/blt_research/三验证)+ HAT 系
  (7B/70B 实证 + HF 权重),全部是 2026 年的活工作。**这个引用墙本身就是
  "生态位闭合"最硬的证据。**

### 2.2 部分推翻项:"字节级 MTP 训练动力学无人做"需要修正

docs/17b §5 把"字节级 MTP 训练动力学系统研究"列为残余研究问题之一。补充调研
发现它**已被部分覆盖**:

- **《Pre-Training Curriculum for Multi-Token Prediction in Language
  Models》(ACL 2025 长文,2025.acl-long.1243)**:1.3B/3B 规模的 **byte-level
  多头 MTP** 系统研究——静态 vs 课程式 MTP 目标、线性头 vs transformer 头、
  逐头接受率分解、BLIMP 语言学现象逐项分析。其核心发现(byte-level MTP 收益
  大于 subword-level;反向课程产生更丰富的隐状态)**已经进入主会**,且与 bltz
  的"字节级多未来监督"高度同域。
- **仍然空白**的部分收窄为:梯度冲突层面的训练动力学(gcos 类测量)、
  Δ 嵌入的"距离场"结构分析、边际并行的校准分析。这三块确实没人做,
  但它们合起来是一篇**分析型小论文**的体量,不是架构论文的支柱。

### 2.3 核实项:思想渊源三先例全部坐实

- **SeismoGPT(2606.10868)**:一手核验——"single shared MLP conditioned on a
  learned per-horizon embedding"(e_h 加法注入,z_t + e_h),与 bltz 的
  concat[h, Emb(Δ)] 属同一机制模式。**docs/16 §5.3 的判断成立且只能更保守**:
  连"加法 vs 拼接"这种实现差异都不构成区隔素材。
- **CSTF / "TempField"(2608.25823)**:一手核验——query-conditioned 连续时空
  温度场解码器,lead time 作为显式查询坐标(配空间梯度/时间差分/尺度一致性
  正则)。神经场式"时间偏移即查询坐标"在连续域的饱和度比 docs/16 写的还高。
- **MT-GNN(2608.05132)**:一手核验——Fourier 编码 lead time 的单网络多 horizon
  预测(脑网格几何)。同上。

结论:docs/18 §2 的"新主张口径"(可主张 = 把 NTP/MTP 统一为偏移坐标上的条件
分布场;不可主张 = 模式首创/神经场标签)**方向正确,但仍偏乐观**——连"字节级
LM 上无人做"都要加上"截至今日、按我们检索式"的时间状语(§2.4)。

### 2.4 中性项:(h,Δ) 位置截至今日未被占据

2026-08-15 之后的补充检索**未发现**新工作实现"相对字节偏移 Δ 为显式输入坐标的
单一共享解码头 + 稠密多视野监督"。docs/16 §5.2 的负结果表维持有效。但请注意
该结论的三重限定:检索式覆盖、引用图滞后、2026 年该方向月更速度(三个月内出现
Fast BLT/DMBP/MB 系三个占位者)。**空窗是事实,空窗的保质期是未知数。**

## 3. 对项目内部决策链的审计(含"非理性陈述"维度)

用户要求把多次波折纳入评价。以下按时间线审计决策质量,不含褒贬,只看
决策与证据的对应关系。

### 3.1 封存(2026-09-14 上午):证据扎实

功能轴裁决(三大主张被 HAT/Fast BLT/DMBP 独立覆盖)有逐行引文级的证据链
(docs/13-16),封存理由"生态位闭合,不是技术失败"表述诚实。**这是整个决策链中
质量最高的一步。**

### 3.2 复工(2026-09-14 晚):是 re-framing,不是新证据

范式轴复核(docs/16 §5)的贡献是把残余差异从"功能"轴挪到"formulation"轴重新
命名,其负结果表确实成立(§2.4 复核后仍成立)。但请注意三点:

1. **复核没有发现任何新事实**——(h,Δ) 头在封存前就在代码里,SeismoGPT 先例
   在封存前已检索过(同日 docs/16 成文)。改变的不是世界,是描述世界的轴。
2. **docs/16 §5.4 自己留下了限界**:"核查只排除了'别人已做',**没有提供
   '值得做'的证据**。"这句话应该被印在复工交接单的首页。
3. 用户自承复工信心"很大程度上出于非理性的直觉"(docs/18 §1.4 原话记录)。
   直觉驱动开工不是问题——科学史上不乏先例——但直觉不能同时充当
   开工理由和继续理由;它只配充当**一次**点火,不配充当无限续命的燃料。

**同日封存、当日复工,本身就是一个需要被解释的信号。** 最 benign 的解释是
封存时漏掉了一个合理的评价轴;较警觉的解释是封存刺痛了投入感,复工是 motivated
reasoning 的产物。无论哪种,后续的证明责任都转移到"用数字兑现直觉"上——而这
正是复工计划自己写下的(M 系列,docs/18 §4)。

### 3.3 复工后的实际轨迹:偏离了复工时立下的证价值路径

这是本次评审中**对"是否继续"最有信息量的一条证据**,与任何实验结果无关:

- docs/18 §4 的第一批任务写得很清楚:**测量优先**,M1-M5 的任务书全部是
  "把直觉变成数字"(逐 Δ 曲线、m_max 扫描、参数账、稠密 vs 单位移对照);
- 实际执行(AGENTS.md 当前状态 + docs/21/22/25):60k 收尾(合理)→
  **encoder 砍参数(inducing/heads)→ FiLM 头 A/B → 长度分组重打包**。
  这些是效率/工程项,没有一项触碰 M1-M4 中任何"证价值"测量;
- M1(逐 Δ 曲线)、M2(m_max 扫描)、M4(稠密 vs 单位移)、D-5(token 基线
  对照)——**决定论文生死的四个实验,一个未跑**;FiLM 对照协议(docs/22 §3)
  甚至把 concat 对照臂砍掉换成"拿 60k 旧 run 当对照",混淆两处变量。

一个项目在最需要外部裁决证据的时刻,持续选择做**内部顺手的**事,这在行为层面
上已经回答了"项目自己想去哪":它想继续存在,而不是想被审判。这不需要被批评
——它是几乎所有长期项目的自然重力——但它必须被点名,因为它是"是否有必要继续"
这个问题里最诚实的输入之一。

## 5. 去留判断与建议路径

### 5.1 判断框架

"是否有必要继续"不应由直觉或沉没成本回答,应由一条外部可验证的判据回答:

> **能否在可承受的算力内,把产品 B 的六个审稿问题中至少四个变成有数字的答案?**

能 → 继续,按 §5.2 的实验包执行;不能或不愿 → 收尾,以 docs/17b 的形态归档
(它已经是高质量的)。

### 5.2 若继续:决定性实验包(替代当前的效率微调)

优先级从高到低,全部对着审稿问题,不再新开工程项:

1. **D-5 + M4 合并执行**(回答两个问题):token 基线(脚本已就绪)同数据
   同预算起跑 + 稠密多视野 vs 单位移两次短训。V100 集群,估 1-2 周。
2. **M1 + M2**(本机,小时级-天级):逐 Δ 曲线 + m_max 扫描——产品 B 的
   "场结构"一节的全部素材。
3. **D-6 质量 × 吞吐 Pareto**(回答"边际解码代价"):多 θ_stop 生成 +
   NFE/字节 + 词界对齐率。
4. 仅当 1-3 全部给出正面数字,才谈 ≥300M 复证与写作。

### 5.3 预先写下的 kill criteria(满足任一即收尾)

1. M4:稠密多视野 vs 单位移在同规模下**无可见差异** → formulation 的
   "稠密监督"卖点消失,产品 B 塌缩为纯实现变体;
2. D-5:同 BPB 口径下输给 token 基线 > 预设阈值(建议 10%)→ 效率与质量
   双主张均不可守;
3. D-6:Pareto 曲线上被"现成 BLT 124M 配置缩到同规模"(官方 repo 可调,
   见三验证)支配 → 连"同生态位内更优"都不成立。

任一中两条,以高质量负结果 + 现有 docs 档案收尾——负结果本身(纯边际解码 +
词界停止在字节级的系统性测量)有独立引用价值,不丢人。

### 5.4 明确的反建议

- **不建议**以"继续打磨架构/精调参数"形态推进(docs/21 精调清单、后续
  encoder/头变体):这些工作在论文叙事里没有位置(参数效率不是本项目的主张),
  且 §3.3 已显示这类工作具有"顺手感",会无限稀释证价值的算力;
- **不建议**以"等 1B 概念验证"形态推迟审判:规模放大不能回答 §4.2 的
  审稿问题,只会放大沉没成本;
- **不建议**再用"换一个轴重命名残余差异"的方式决策去留(封存→复工已用掉
  一次):下一次决策必须由数字触发。

## 7. 追评(2026-09-15):formulation 优先策略的专项评估

> 触发:用户澄清提问对象——"我问的是 formulation 本身的价值,不是当前结果的价值",
> 并阐明既定战略(docs/18 已载):新 formulation 若 work,解码头作为主打架构创新、
> 建模视角作为理论支撑、M1-M4 作为叙事数据分析抓手。本节是对**该战略本身**的
> 外部评审,不是对结果的评审。

### 7.1 formulation 的可分离主张与各自强度

"单一共享 (h,Δ) 解码头 + 稠密多视野监督"不是单一主张,是三个可分离的结构性
主张,强度不同:

| # | 主张 | 强度评级 | 理由 |
|---|---|---|---|
| F1 | **NTP ⊂ MTP 统一**:Δ=1 只是场的一个查询,单一接口覆盖一切 | 中 | 美学+参数账级别;易被表述为"SeismoGPT 头的字节版",单靠它撑不起主打创新 |
| F2 | **因果性 by construction**:边际性来自查询语义(h=过去,Δ=坐标非内容),非来自掩码构造 | 中强 | DMBP 的并行不违因果需要论证(重复向量+RoPE,L369-373);Fast BLT 靠扩散近似;bltz 是结构性边际——"结构性 vs 构造性边际"是清晰的 formulation 级区分,**用户当前叙事中可能被低估的一张牌** |
| F3 | **监督范围内的窗口自由**:m_max 1..48 纯运行时旋钮,无需重训 | **强(条件性)** | 唯一可能变成"能力"的主张;现成对照:DMBP 的 n 超训练视野(t+2)掉点、峰值 6-7(§6.2);若 M2 显示 16→48 质量平坦,这是 formulation 派生、邻居没有的性质——**三个主张里唯一配当"主打"卖的** |

### 7.2 对战略本身的三处修正(不是否定)

1. **"work well" 必须用 formulation 语言预先定义。** loss 下降不构成 formulation
   的证实(任何 MTP 变体都 loss 下降)。可证伪签名清单:
   ① Δ 嵌入距离场结构(M1;60k 已有相邻 cos 0.71 的正面苗头);
   ② m_max 在监督范围内质量平坦(M2 = F3 的直接检验);
   ③ 稠密监督 > 单位移监督,同规模 A/B(M4 = 稠密监督主张的直接检验);
   ④ 每 horizon 零参数成本(M3,构造上恒真,只需记账)。
2. **"建模视角作为理论支撑"目前是一个假设(H1),不是理论**——这没问题(多数
   ML 论文的 theory 即此粒度),但必须形式化为可写进论文的骨架:**分段生成过程**
   (停止规则定段长 → 段内字节从场边际独立采样)+ **显式近似假设**(词内条件
   独立性,给定 h)+ **可测签名**(D-7 自验证一致率即 H1 最直接的检验;
   词界对齐率、提交跨度分布为间接签名)。这样 H1 从口号变成承重墙。
3. **主打解码头存在可抄袭性问题**:头本身可被 Fast BLT/DMBP 一个周末复制。
   护城河 = "头 + 场结构分析 + 它解锁的能力"的组合。叙事顺序应为
   formulation → 可测结构后果(M1/M3)→ 解锁的能力(F2/F3)→ 头作为实现,
   而非倒过来。

### 7.3 价值上限的条件化判断

- **F3 与 M4 双正** → formulation 撑得起一篇真论文的主打贡献
  (Findings/短论文起步,叙事好可冲主会);
- **M4 null**(稠密 vs 单位移无差异)→ "稠密多视野监督"卖点消失,formulation
  塌缩为实现选择,剩余价值 = F2 的简洁性论证 + 训练动力学分析(§4.2 的小论文);
- **F3 null**(m_max 超某值质量显著下滑)→ "窗口自由"不成立,formulation
  与 DMBP 的单位移+复制外推相比无本质优势,主打创新主张不可守。
- SeismoGPT 先例(§2.3)意味着所有正向结果都必须体现为**字节域特异后果**,
  否则审稿人一句 "applied horizon-conditioned head to bytes" 结束战斗。

**结论:formulation 本身有价值,其价值上限由 M2/M4 决定;当前战略(头为主打、
建模视角为支撑、M1-M4 为抓手)自洽且与举证责任匹配,可以执行,但 §7.2 的三处
修正应在开工前落进文档。**
