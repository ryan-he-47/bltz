## 1. 动机

大词表是固定成本:新语言、新域、微调适配都要围绕它重新纳税。bltz 的假设
是把 token LM 范式的两端换成**可学习的字节级 I/O**,保留其全部训练/推理
范式:变长字节 patch 经 Set Transformer 编码为 latent,标准 transformer 骨干
做 patch 级自回归,条件神经场头 `(h, Δ) → byte` 并行预测多未来字节(MTP),
推理以 space-like 词界自然停止、熵仅兜底(D11)。设计公理:**架构不得依赖
高精度分词算法才能工作**——分割是给架构减负的先验,不是拐杖。

三个高风险设计点(D1 纯并行边际解码 / D2 patch 局部编码器 / D5 模型自分割)
被显式设为实验本体:它们与 BLT 系文献结论相矛盾,work 与否都产生信息。

## 2. POC 实测摘要(20k 步,137M 参数,0.93B 字节,详见 docs/10)

- 训练全程稳定(gn≈0.1、2 次 spike、无 OOM);模型确实在学:近场 CE 持续
  下降,词边界知识明确(词界 space 概率 0.79;词中截断会自信续写)。
- Δ 嵌入学出光滑距离场;编码器现阶段为字符级压缩(无语义信号,早期现象)。
- 生成早期退化(重复吸引子),与数据量(缓存的 2%)自洽。
- 推理停止规则的关键修正(D11):词界是**低熵**确定处,BLT 式"停在高熵"
  永远落不到词界;改为词界自然停止后提交跨度成为词形分块(3.3-3.5 字节,
  对齐率 1.00)。

## 3. 方法学教训(可复用)

1. **测量先于干预**:full-param 梯度余弦一度显示"多任务冲突"(-0.40/-0.62),
   修正测量(∇_h 规格 + 模块分解 + 组合对齐 + 随机对照 + 轨迹)证明为
   测量伪影——负余弦全在 Δ 读出层,骨干从未被撕扯(docs/10 §3.2b、
   docs/11/12)。若当时直接调 λ/n/头,就是一次基于伪影的架构修改。
2. **全量内存必须实测**:三次 OOM(缓存构建 / reader 偏移表 / 尾部 worker)
   同出一源——小规模 dryrun 测不出全量内存剖面;另:mp.Pool 静默挂死
   无报错,**心跳打印是无人值守任务的最低可观测性**。
3. **WSD 的价值在分支点**:里程碑快照(weight-only)使 decay-on-demand 与
   探针分叉成为零成本操作;只留尾部 ckpt 等于废掉 WSD。
4. 完整工程坑位清单:`docs/07` §4(十条,全部实测)。

## 4. 封存原因(技术陈述)

2026-09 文献普查(docs/13-16)确认本项目三大主张已被外部工作独立覆盖:

| 主张 | 外部实现 |
|---|---|
| 无词表层级字节 I/O + 鲁棒/可迁移 | HAT(Aleph Alpha,2501.10322;7B/70B 实证,权重已发布,2603.15953) |
| 并行局部字节解码 | Fast BLT-D/DV(Meta,2605.08044,块扩散+验证);DMBP(2608.15454,LCA 掩码边际) |

残余差异为 formulation 级((h,Δ) 场头、词界停止+确定性分割组合、训练动力
学诊断、Set 编码器),不足以独立成文(docs/16 §4)。在 novelty 空间闭合的
前提下继续投入不符合研究经济学,故封存。POC 证据未显示架构不可行——
**封存原因是生态位,不是技术失败**。
