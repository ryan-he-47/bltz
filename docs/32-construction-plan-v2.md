## S0 — 本机字节串自编码器原型(先行,卡住再往下)

**目的**(用户原意):① 找出"多大 AE 能胜任混合 BPE 短字节串重建"——过大
会过拟合、嵌入空间崎岖难预测(CoSE Table 2:D 越大重建越好但预测与 SC
越差,存在甜点);② 分析嵌入空间形态,给骨干可预测性一个前置判断。

**数据**:本机 `data/cache_dryrun`(不够就拉一个小缓存);Qwen3.5-2B
tokenizer 文件从集群 scp(几 MB,不要权重);增强 BPE 分割器离线预烘焙
(每样本掷一次定型,p=0.5——单遍训练下与在线等价,已拍板)。

**规模网格(已拍板)**:`d_emb ∈ {32, 48, 64}` × enc/dec 宽度 `{256, 384}`
共 6 组,**从 32-256 组起跑**;enc 2 层 inducing 8 不变,**patch 内字节
位置编码拼接保留**(d_byte+d_pos,用户提醒);dec = 条件查询头(film,
hidden 512);每组几万步量级,本机可承受。

**测量**:
- 重建:字节 CE / **exact-match 率**(整串全对)/ EOS 位置准确率;
- 几何:PR / anisotropy / kNN-CC / **SC**(k-means 多 k 均值,CoSE 口径);
- 可预测性旁证:相邻 patch 嵌入的局部线性度( cheap probe,供参考)。

**产出**:选定 AE 配置 + 嵌入几何报告(回填本文);判"空间太崎岖"的
预警信号:exact-match 高但 SC 低、PR 贴近 d_emb 上限、随机串 PR 与真实串
PR 倒挂(对照 v1 的 35-45 经验值)。

**S0 回填(2026-09-17/18,dryrun 池 35,851 条去重串 / val 1,792)**:

| 配置 | val loss | val EM | 备注 |
|---|---|---|---|
| 32-256 | 0.171 | 94.3% | 4.35M 参数;PR 28.4/32、aniso +0.117、SC 0.105;val loss ~3k 步见底后缓升(池小过拟合) |
| 32-384 | 0.178 | 93.8% | 加宽无益(同过拟合) |
| **48-256** | **0.076** | **97.4%** | **明显跃升;宽度 256 已够** |
| 48-384 | 0.082 | 97.1% | 同上 |
| 64-* | — | — | **弃跑**(2026-09-17 用户裁决:GMM 高维拟合难,见 docs/31 §5) |

读法:48 维是当前甜点候选(EM 97.4%,val loss 2.3× 好于 32);宽度
256 封顶;几何整体健康(近满秩、低各向异性——重建塑形把 v1 的窄锥
摊开了)。池子只有 35.8k 条去重串是主要限制,S1 全量缓存后数字还会涨;
CoSE 低维利于预测的先例 + 48/32 的边际收益 = **48-256 定为 v2 AE 基座
(2026-09-18 用户拍板确认)**。注意:S3 用的冻结 AE 需在 S1 全量缓存上
重训(dryrun 池仅 3.6 万条,过拟合边缘);S1 完成后先补一刀 AE 全量训练
(规模同 48-256,步数按池规模定,几十万步量级,V100 上很快)。

## AE 补救工具箱(2026-09-19 用户备录)

> 触发条件:三件套验收(几何/频率分层 val/distinct 曲线)异常,或 POC
> 骨干 NLL/生成读数不理想。四条都是 AE 数据侧的改动,不动骨干。

1. **去重词库数据集**:全数据集 unique patch 去重成词库,平衡高频/低频
   串的训练信号——拉平 Zipf,嵌入空间会把容量从头部挪向稀有串。风险:
   稀有串里混着随机碎切产物与噪声串,平衡可能把容量浪费在垃圾上;且
   特征提取器是否该偏离部署分布,无先验答案。用户注:会改变空间形成
   方式,好坏未知。
2. **typo 簇增强**:不仅重建真词,还重建含微小 typo(错字/缺字/重复/
   交换)的 patch,**重建目标是 typo 串本身(不是去噪回真词)**——把
   一个数据点变成围绕正确词的密集点云。双重收益:(a) 潜空间局部致密化;
   (b) 骨干预测嵌入稍有偏差时,落进 typo 簇 → 解码成近似串,而不是
   彻底 OOD 崩溃(误差以 typo 形式柔和表达)。代价:簇变宽,半径过大时
   近形词可能互相渗流。
3. **合成词 val 探针**:拼写合理但真实文本中极难出现的伪词(如
   'blorft'、'draction'),直接测字符串级泛化(=频率分层 val 的零次桶
   的人工强化版),量化过拟合程度。成本极低。
4. **随机切分增强回归**(待定):v1 式随机切/合 patch 可极大提升数据
   丰度;顾虑是低质量碎片(单字节、断 UTF-8 序列)过多阻碍训练。若启用
   需加质量下限(最小长度、不在多字节字符内部断)。到时候再议。
