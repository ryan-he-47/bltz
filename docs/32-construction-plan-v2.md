## S0 — 本机字节串自编码器原型(先行,卡住再往下)

**目的**(用户原意):① 找出"多大 AE 能胜任混合 BPE 短字节串重建"——过大
会过拟合、嵌入空间崎岖难预测(CoSE Table 2:D 越大重建越好但预测与 SC
越差,存在甜点);② 分析嵌入空间形态,给骨干可预测性一个前置判断。

**数据**:本机 `data/cache_dryrun`(不够就拉一个小缓存);Qwen3.5-2B
tokenizer 文件从集群 scp(几 MB,不要权重);增强 BPE 分割器离线预烘焙
(每样本掷一次定型,p=0.5——单遍训练下与在线等价,已拍板)。

**规模网格(已拍板)**:`d_emb ∈ {32, 48, 64}` × enc/dec 宽度 `{256, 384}`
共 6 组,**从 32-256 组起跑**;enc 2 层 inducing 8 不变,**patch 内字节
位置编码拼接保留**(d_byte+d_pos,用户提醒);dec = 条件查询头(film,
hidden 512);每组几万步量级,本机可承受。

**测量**:
- 重建:字节 CE / **exact-match 率**(整串全对)/ EOS 位置准确率;
- 几何:PR / anisotropy / kNN-CC / **SC**(k-means 多 k 均值,CoSE 口径);
- 可预测性旁证:相邻 patch 嵌入的局部线性度( cheap probe,供参考)。

**产出**:选定 AE 配置 + 嵌入几何报告(回填本文);判"空间太崎岖"的
预警信号:exact-match 高但 SC 低、PR 贴近 d_emb 上限、随机串 PR 与真实串
PR 倒挂(对照 v1 的 35-45 经验值)。

## S1 — 集群缓存 v2(增强 BPE)

- 缓存格式:**预烘焙单套分割**(bytes + units,同 v1 形态)——分割在
  构建时一次性定型(p=0.5 合成规则);不存双 mask、不做在线随机
  (单遍训练等价性,docs/31 §5)。
- 全量 10BT 重建(新目录,旧缓存 85GB 是活资产不删;scratch 预算:
  现 ~120GB + 新缓存 ~90GB ≈ 210GB,300GB 配额内,先算后跑)。
- 验收:抽样对拍——间隙集合 = 两方并集、一致间隙必切、统计分布
  (patch 长度直方图 vs v1)入档。

## S2 — 骨干 + MDN 实现与本机冒烟

- `bltz/models/`:AE 模块(Eθ/Dθ 独立可训)、MDN 头(π/μ/σ,fp32 NLL,
  σ 下限)、骨干输入投影 48→768;`BltzLMv2` 组装,detach 边界明确。
- 推理循环:BOS → GMM 采样 → 解码到 EOS →(可选)回投影;温度 τ。
- 本机冒烟:小配置过拟合单 batch(重建与 NLL 分别能降到接近 0)、
  采样一条生成链不崩;测试套件新增:test_ae_recon / test_mdn_head /
  test_seg_v2(增强 BPE 合成规则)。
- MDN 卫生:σ=ELU+1+ε;NLL spike 走 spike_skip;记录 π 熵与有效分量数
  (坍缩早期信号)。

## S3 — 骨干 POC(集群,V100;frozen 先行,joint 降级备选)

- **臂 F(frozen,先行)**:S0 选定 AE 预训练权重冻结 → 骨干 MDN 训练。
- ~~臂 J(joint-decoupled)~~:**降级为备选**(2026-09-17 拍板)——frozen
  效果特别好就万事大吉;不佳再上 joint(AE+骨干同步、梯度硬切断、
  双 Adam 组),用于区分"嵌入空间冻结错位"与"联合震荡拖垮"两种病因。
- 规模建议:20k 步 batch 16 先读(每臂 ~6h),健康再上 60k;LR 沿用
  4e-4 WSD;两臂各一份 diag。
- 读数:字节 CE(解码口径)+ exact-match + 生成定性 + π 熵/分量使用率;
  对照锚 = v1 各 run(2.50 底线、k1-mix 2.173)。
- CoSE 动态观察(用户标注低可信度)仅作排查线索:F 臂若骨干不适配
  (NLL 不动)→ 查嵌入空间冻结错位;J 臂若骨干被噪声嵌入拖垮 →
  查 AE 早期震荡;两臂都不动 → 回 S0 审嵌入空间。
