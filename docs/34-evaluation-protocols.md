## 2. AE 侧协议(回答:嵌入空间本身能不能用、结构是什么)

| 协议 | 跑法 | 指标与诊断目标 |
|---|---|---|
| 重建四指标 | `scripts/train_ae.py` 内建 val | CE / bacc / **EM(整串含 EOS 全对)** / val_loss;最低能力线 |
| **频率分层 val** | `scripts/diag_ae_v2.py <ckpt> --cache/--units-pkl` | val 串按训练抽样频次分桶(zero/low/mid/high)报 CE/bacc/EM;**zero 桶=真字符串级泛化**(32 维全量:93.6%)。解决"stream val 同分布、测不出泛化"的口径缺陷 |
| 几何套件 | 同上 | anisotropy(窄锥=坏)/ PR 参与率(有效维数)/ kNN-CC(簇性)/ **SC 轮廓系数**(CoSE:与下游可预测性相关 0.92)/ NN 近邻可解释性 |
| distinct 曲线 + Heaps 外推 | 同上 | 有效样本宇宙量(~76M 串),坐实"样本量由分割多样性界定";尾部不可记忆 ⇒ 零次桶非污染 |
| **变体分辨率(频次分档)** | Temp 探针 probe_variant_sep | decode(encode(x))==x 按**变体自身**频次分档;结论:自然表面形式(句首大写/前导空格/复数 -s)各档 0.97-1.00;非自然形态(词中乱序大小写)坍缩=纠错行为 |
| **方向一致性** | 同探针 | Δλ(变体对)两两余弦 vs **无关配对基线** + 平均方向对齐度;大写方向 +0.654、复数 +0.447 存在,空格无单轴(弥散)。**回答"语义属性是否以线性方向承载于 λ"** |
| **typo 三件(设计意图口径)** | `scripts/diag_ae_typo.py <臂...> --cache` | σ_typo(typo 等效噪声,变体-源词逐维位移)/ **typo 保留率 fid**(忠实度,plain 0.876→t04 0.977,case 0.583→0.92)/ 吸引失败 snap(云塌回源词)/ σ_typo 标定分档噪声下 failure 四分(exact/typo/远真词/碎片) |
| 真词分离 C1/C2 | 同上 | C1 规范形去重队列的 NN 距离分布(修复"高频真词被分割变体钉死"的退化);C2 点云余裕 margin=d−r 与碰撞率(剂量交叉在 t01) |
| 中点解码 | 同上 | decode((λ_a+λ_b)/2):近形混合或选边,非 OOD——消歧压力的直接观察 |

## 3. 骨干能力协议(回答:预测本身多强、强在哪弱在哪)

| 协议 | 跑法 | 指标与诊断目标 |
|---|---|---|
| 留出 NLL | `scripts/diag_v2.py <v2> <ae> --units-pkl` | 与训练 NLL 之差=泛化间隙(60k/1B 均 ≈0,欠拟合区);**跨 λ 空间不可比** |
| **下一 unit 三读出对照** | 同上 | argmax-π / min-σ / conf-rerank 的 EM、编辑距离分布(med/NED/prefix/edit≤k 占比);失败模式定量(过半 ≤2 编辑=错别字级);重排=免训练收益(+3pp) |
| top-k 覆盖 | 同上 | top5 解码候选含真值率(1B:51.2%);**排序 gap = 覆盖 − argmax EM**,当前最大短板 |
| π 统计(坍缩预警) | 同上 | 熵 / 有效分量 1/Σπ² / top1 share;1=坍缩、64=均匀瘫,~4-5 健康 |
| persistence 基线 | 同上 | "预测=上一 unit"的 EM(0.07%),排除"抄前文"假象 |
| teacher-forced 字节 CE | 同上 | **已知锐度伪影**:解码器太锐,答错时置信地错(25.6 nats),不是 LM 口径损失;留档仅作解码锐度证据 |
| per-type 切片 | (v1 edelta 传统,半成品) | space/digit/letter/punct 分层 CE;v2 版未专门重跑 |

## 4. 生成协议(回答:自回归滚动到底行不行、哪一环断)

| 协议 | 跑法 | 指标与诊断目标 |
|---|---|---|
| 自由滚动样本 | `scripts/diag_v2.py` 生成段 | prefix 16 → 滚 64 步,τ 扫描 × distinct-n × mean conf;**样本全文在日志里(checkpoints/diag_v2_*.log),之前只给你看了残片——协议本身的产物是全样本** |
| **生成解剖** | Temp 探针 probe_gen_autopsy | (A) 真值上下文单步 argmax EM 分位(~34%,与 GPT-2-small 级下词 top-1 同量级);(B) 滚动逐步日志(top3 候选/π/conf/真词否)——看到周期-2 吸引子(碎片词↔空格);(C) 生存曲线(真词率按步)对比 reproject on/off:**回投影有害**(软误差硬化,生存 0.25 vs 0.5-1.0) |
| **verifier 门控滚动** | 同探针 | top-5 内取首个 conf>阈值的候选:文本骨架立刻浮现("and X the Y. SoB are Z…"),all-bad-fallback=0 → **乱码主因是读出策略,不是单步能力** |
| **词表吸附解码(snap,2026-09-22 用户提出并验证)** | `scripts/snap_decode.py <v2> <ae> --units-pkl [--gen]` | 词表(Qwen ∪ 缓存 top-N)过编码器成嵌入矩阵;三读出对照:**gmm 密度吸附(Σ_k π_k·N(V_n;μ_k,σ_k²))EM 37.9% > 解码器 34.6% > 余弦 34.7%**(σ 投票信息真实);合法词保证消灭乱码;**首个通顺英文样本**(τ=0 "and in the 1990s. The first time…" 带吸引子;τ=0.8 "to be able to get / If you have to get an important part of");覆盖 95.6%(长/稀有 unit 未覆盖,表需扩充) |
