## 2. Stage 3 熵分割臂(规格定稿)

- **熵模型**:d=512 / L=14 / heads=8 / 滑窗 512(~45M;BLT 消融:>50M 收益递减),
  local-block-causal,**换行重置上下文**;数据 = FineWeb-Edu 2~4B 字节(与主训练同分布);
  LR 4e−4 cosine。本机可训(~15h),或集群 CPU 旁路。
- **熵分割**:近似单调约束 `H(t) − H(t−1) > θ_r`。**θ_r 标定到与固定分割臂相同的
  平均 patch 长度**——否则两臂不可比,这是消融公平性的关键。
- **纪律(消除配置漂移)**:Stage 1 冻结时打 **git tag**;熵臂从同一 tag 分叉,
  只允许改分割相关配置。
- **验收 G3**:两臂 BPB / 诊断(D-1、边界一致性)/ 效率对比报告 → **用户选型**主分割策略。

## 3. Stage 4 1B 概念验证(规格草案,预算待拍板)

- 骨干 d=2048 / L=25(对齐 BLT-1B global);条件头 6×4096(~110M);编码器 ~12-16M。
- 数据:FineWeb-Edu sample-10BT 全量(~44B 字节 ≈ ~7e9 patch);
  6ND ≈ 4.6e19 FLOPs ≈ V100 fp16 单卡 ~5-10 天(可截 20B 字节减半,用户定)。
- 工程:fp16+GradScaler(已就绪);断点续训+rotation(已就绪);训练在轨确认后
  移交用户盯盘(MoB "我盯不消耗token" 模式)。
- **验收 G4**:留出 BPB 达 twin 外推的合理水平;CUTE 风格字符任务显著强于同规模
  token 基线(定性复现 BLT 的字符优势);多 θ_stop 生成可读;NFE/带宽核算成表。
  总报告 `docs/05-final-report.md`(编号以届时实际为准)。
