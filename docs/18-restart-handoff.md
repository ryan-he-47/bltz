## 4. 第一批任务(测量优先;只动诊断/脚本,不动架构)

> 通则:每项任务开工前先写"判据 + 资源估算 + 可能推翻的假设";结论写回 `docs/`,由用户拍板下一步。编号 M = measurement。

- **M1 — 逐 Δ 质量/校准曲线**(复用/增强 `scripts/diag_poc.py`):按 (k, r) 分层的 accuracy / entropy / 校准(ECE 或置信-正确率),给出 H(Δ) 结构形态。判据:趋势可解释(不设通过门槛);产出"场结构"实验节素材。成本:本机 + 已有 ckpt,小时级。
- **M2 — m_max 扫描**:在监督范围(Δ≤48)内把推理窗口 `m_max` 由当前 16 提到 24/32/48,测质量 × 吞吐 × 提交跨度。判据:窗口可调且质量曲线形态(预期平;若明显下滑,说明 k≥2 段质量不足)。成本:本机,小时级。(对照:DMBP 的 n 超出训练视野会掉点。)
- **M3 — 参数/算力账**:每 horizon 参数成本与 FLOPs——本架构(0 新增、仅 Δ 表)vs 多头 MTP(n 头)× DMBP 式(NT+MB+τ)vs BLT-D(扩散)。判据:可核对的表格;产出摘要级对比。成本:纯统计 + 少量 profile。
- **M4 — 稠密多视野 vs 单位移监督(对照实验)**:同规模、同参数量、同数据下,{k≤3 几何衰减} vs {仅 t+2 单位移};比质量/样本效率。判据:差异是否显著 → 决定"稠密监督"是否为卖点。成本:两次短训(twin 级本机或集群小 run),天级。
- **M5(可选,关键升级)— 连续 Δ 编码**:把 48 行离散表换成标量 Δ 的连续编码(Fourier/sinusoidal features),做**插值**(留出中间 Δ)与**外推**(Δ>48)测量。判据:若成立 → "场"名副其实且与 SeismoGPT 划开;若 null → 弃用该措辞,保留离散版主张。成本:改一处头 + 一次短训,天级。

**执行顺序建议**:M3(零成本)→ M1/M2(本机)→ M4(决定叙事)→ M5(可选,决定措辞)。
