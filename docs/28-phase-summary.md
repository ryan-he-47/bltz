## 1. 本轮长程实验结果分析(2B run + 两次干预 + 退火探底)

**时间线**(docs/27 §4 有全程干预记录):
1. 2B run(556282)起步健康,T1' 集群收益兑现(~0.85s/step);
2. ~36k 后 loss 平台(2.57-2.62)——与 60k 的衰减起点同位,判稳定段
   LR 4e-4 为长程约束(两次 run 一致:"恒定慢磨、衰减兑现");
3. 一次干预(decay_frac 0.4→0.84,即时线性衰减,resume@72250):LR 如期
   下落,但 loss 到 140k 仍 ~2.53-2.55;
4. 二次干预(用户拍板,河谷理论):暂停主 run,退火探针 565575
   从 ckpt@140750 以当前 LR 2.21e-4 线性退到 2.2e-5,10k 步。

**退火结论(已画 `viz/anneal_vs_main_lin.png`)**:
- 终值 2.52(均值 2.553→2.520,-0.033);**平滑后可见真实、平稳、干净的
  下降趋势,且到 2.2e-5 时仍未走平**——盆地底部未被完全触及(底部 ≤2.52)。
  模型对 LR 下降响应健康,无非线性病态。
- **"振荡变大"证伪**:resid_std/1k 步 退火段 0.026-0.031 vs 主 run 同区
  0.018-0.031,峰峰值同量级(0.11-0.13)——用户看到的"毛躁"来自
  退火 log_every=25 vs 主 run 50 的采样密度差 + 噪声带相对均值占比。
  量化后振幅统计上不变。4 次 spike_skip 均正常拦截。
- **模型当前盆地底:混合 loss ≤2.52**(未完全探底)。LR 不再是主约束;
  按 docs/27 §4.2 判读规则,约束转向容量/数据/目标——但"底部未尽"意味着
  主 run 续完仍有温和收益可收。

**跨 run 对照**:60k 终值 2.556(0.49B patch);2B@140k ≈ 2.55,
退火后 2.52(1.15B patch)。**2.3× 数据只买 -0.03**——长程边际收益在这个
模型规模下已经很薄。

**encoder 有效维度补注(2026-09-16 晚,随机串探针)**:enc PR 看似很低
(~35/768),但喂 200 条随机小写串 PR=39.0、200 条随机可打印字节
