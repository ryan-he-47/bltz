## 4. 结论(对复工第一批任务 M1-M5 的输入)

1. **架构在 60k 规模继续健康**:无饱和迹象、未收敛、无表示层冲突。
   长跑(或加数据)仍是纯收益方向。
2. **停止规则(D11)与边界知识良性互动**:提交跨度随训练变长变稳,
   词界对齐率保持 1.00;`θ_fallback=2.5` 仍过紧(远 Δ H 常态超阈),
   维持 ≥3.5。
3. **编码器语义缺位在 60k 依然成立**——"字符压缩器"是结构特性而非
   纯早期现象,若下游需要 patch 语义,可能要在训练信号或池化上想办法
   (列入 M 系列候选,待拍板)。
4. **数字/标点弱项**(4.26/3.84)持续;数据配比或更大样本量可解。
5. Δ 距离场(相邻 cos 0.71)已相当光滑——**M5 连续 Δ 编码(傅里叶特征)
   有了更好的起点**;这是与 SeismoGPT 类近邻划开的关键实验,优先级建议上调。
