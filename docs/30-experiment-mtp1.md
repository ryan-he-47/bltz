# 30 — MTP 监督深度对照实验:n_patches_ahead 3→1(2026-09-16 晚,用户拍板)

> 起因:用户调研到外部研究结论——**子词级(subword 及以下粒度)MTP 对小模型
> (尤其我们这种 ~124M 量级)的学习能力有损害风险**。本架构的默认目标恰是
> 字节级 MTP(D4:n_patches_ahead=3,逐字节监督 3 个未来 patch)。开一个
> 对照臂验证该结论在本模型是否成立。

## 1. 设计

| 项 | 值 | 备注 |
|---|---|---|
| 唯一变量 | `loss.n_patches_ahead` **3 → 1** | 配套 `model.k_max` 48 → 16(= n×l_max) |
| LR 调度 | **与 60k run 完全相同** | WSD:lr 4e-4 / warmup 1000 / decay_frac 0.4 / final_frac 0.1(default.yaml 原值) |
| steps / batch | 60000 / 16 | 同 60k run;fp16(V100) |
| 其余 | 现默认配方 | **film 头**(2026-09-16 起常驻)+ T1' grouped encoder + head_grad_ckpt |
| ckpt / 输出 | `ckpts/twin60k_mtp1/` → `~/bltz/ckpt_final/60k_mtp1/` | sbatch:`slurm/bltz_train_mtp1_60k.sbatch` |

## 2. 已知混淆(如实记录)

- 60k 对照臂(547403,终值 2.556)是 **concat 头 + 旧画布**;本臂是 film + T1'。
  T1' 逐元等价(无影响);**头型不同是真实混淆**——若出现显著差异,严格归因
  需补 concat+k1 臂。按 POC 定性口径(D10)先读趋势,用户拍板以后都用 film,
  故本臂即"现行默认配方的 k=1 版"。
- 查询量变化:k=3 时每 patch 平均 ~130k 查询/step;k=1 后 ~1/3,头的有效
  监督密度与算力消耗同步下降(步时应明显变快——本身是个附带观测点)。

## 3. 判读规则(对照 60k 终值 2.556 / 20k 的 2.66)

- mtp1 终值**显著低于** 2.556(≳0.02 量级)→ 外部结论在本架构成立:
  深 MTP 有害,议是否 k=1 常驻 / 补 k=2 臂找拐点。
- **打平**(±0.01)→ k=3 无害亦无益;降 k=1 白省头算力,可定为新默认。
- **显著更差** → k=3 深监督是正贡献(稠密监督信号对小模型有用),维持现状;
  外部结论不适用于字节级条件头形态。
- 收尾跑 diag_poc 全套,对照 docs/20 基线(重点看 edelta 近场 CE 与词尾/词界:
  若 k=1 这些反而更好,说明深监督在稀释近场容量)。

## 4. 结果(job 565864,2026-09-17 回填)

**训练**:60k 完成,~0.77s/step(60k 臂 1.09s——头查询量 ~1/3 的算力红利
兑现),raw 终值 ~2.22。**raw 值不可比**(k=1 混合只含近场查询);同口径
回测(k1-mix,cache 尾 8 序列,同批):

| ckpt | k1-mix | k3-mix |
|---|---|---|
| **mtp1@60k(film)** | **2.173-2.177** | N/A(Δ 表 k_max=16) |
| anneal10k@148.7k(film,k3,1.15B patch) | 2.1771 | 2.5023 |
| 60k concat(k3,0.49B) | 2.2233 | 2.5380 |
| 20k concat | 2.3436 | 2.6332 |

**判读(照 §3 规则):外部结论方向成立——但表述要精确。** 同预算下 k=1
比 k=3 近场好 -0.046(2.177 vs 2.223);更刺眼的是 **mtp1@60k(0.49B patch)
在近场追平了 k=3 的 148.7k 退火权重(1.15B,2.3× 数据)**——深 MTP 监督
确实在稀释小模型的近场学习容量。逐切片(diag_poc edelta):数字类 CE
2.634(k3 各臂 4.1-4.7,巨幅)、space 1.221(vs 1.525)、word-first 2.15
(vs 3.02)、letter 2.31(vs 2.85)——近场全切片大幅占优;唯 Δ=1 词尾
1.578 略逊于退火臂 1.434(词界探针 space 置信 0.78 ≈ 0.80 打平)。

**代价(如实记录)**:① Δ>16 能力整体不存在(头表 k_max=16,远场查询
不可评估);② **demb Δ 距离场退化**——相邻 cos 0.272(k3 退火臂 0.807),
cos(1,16) -0.053:深监督曾是 Δ 几何组织的来源;③ 生成定性:mpt1 更少
回声循环、更多新颖片段("in the 19t0s…",θ=2.5 臂见 "1980s with the
developmen"),但也漂出外语碎片("histo de la cosie")。

**留给用户拍板的下一步**:k=1 常驻 / 补 k=2 臂找深度拐点 / 维持 k=3
(若远场能力与 Δ 场几何被视为资产)。附带观测:推理路径(D11 词界停止 +
逐 patch 自回归)只吃近场,远场 MTP 是训练期辅助——k=1 的近场效率若可
复现,对 scaling 配方是大事。
