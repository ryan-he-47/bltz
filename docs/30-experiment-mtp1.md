# 30 — MTP 监督深度对照实验:n_patches_ahead 3→1(2026-09-16 晚,用户拍板)

> 起因:用户调研到外部研究结论——**子词级(subword 及以下粒度)MTP 对小模型
> (尤其我们这种 ~124M 量级)的学习能力有损害风险**。本架构的默认目标恰是
> 字节级 MTP(D4:n_patches_ahead=3,逐字节监督 3 个未来 patch)。开一个
> 对照臂验证该结论在本模型是否成立。

## 1. 设计

| 项 | 值 | 备注 |
|---|---|---|
| 唯一变量 | `loss.n_patches_ahead` **3 → 1** | 配套 `model.k_max` 48 → 16(= n×l_max) |
| LR 调度 | **与 60k run 完全相同** | WSD:lr 4e-4 / warmup 1000 / decay_frac 0.4 / final_frac 0.1(default.yaml 原值) |
| steps / batch | 60000 / 16 | 同 60k run;fp16(V100) |
| 其余 | 现默认配方 | **film 头**(2026-09-16 起常驻)+ T1' grouped encoder + head_grad_ckpt |
| ckpt / 输出 | `ckpts/twin60k_mtp1/` → `~/bltz/ckpt_final/60k_mtp1/` | sbatch:`slurm/bltz_train_mtp1_60k.sbatch` |

## 2. 已知混淆(如实记录)

- 60k 对照臂(547403,终值 2.556)是 **concat 头 + 旧画布**;本臂是 film + T1'。
  T1' 逐元等价(无影响);**头型不同是真实混淆**——若出现显著差异,严格归因
  需补 concat+k1 臂。按 POC 定性口径(D10)先读趋势,用户拍板以后都用 film,
  故本臂即"现行默认配方的 k=1 版"。
- 查询量变化:k=3 时每 patch 平均 ~130k 查询/step;k=1 后 ~1/3,头的有效
  监督密度与算力消耗同步下降(步时应明显变快——本身是个附带观测点)。

## 3. 判读规则(对照 60k 终值 2.556 / 20k 的 2.66)

- mtp1 终值**显著低于** 2.556(≳0.02 量级)→ 外部结论在本架构成立:
  深 MTP 有害,议是否 k=1 常驻 / 补 k=2 臂找拐点。
- **打平**(±0.01)→ k=3 无害亦无益;降 k=1 白省头算力,可定为新默认。
- **显著更差** → k=3 深监督是正贡献(稠密监督信号对小模型有用),维持现状;
  外部结论不适用于字节级条件头形态。
- 收尾跑 diag_poc 全套,对照 docs/20 基线(重点看 edelta 近场 CE 与词尾/词界:
  若 k=1 这些反而更好,说明深监督在稀释近场容量)。
