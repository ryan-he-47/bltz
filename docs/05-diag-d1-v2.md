# 05 — D-1 诊断判据修订(v2 分层)与首次实测(2026-09-08 晚)

> 性质:**测量方式修正**,设计意图不变。docs/01 §9 D-1 与 AGENTS.md 的判据措辞
> 已同步更新;用户有否决权。

## 1. 发现:v1 判据在 smoke ckpt 上误报

诊断脚本集成检查(scripts/diag_delta.py,smoke ckpt + 干跑缓存)时,v1 判据
("accuracy/entropy 必须随 Δ **逐点**单调劣化")给出 FAIL。但逐 Δ 曲线并非
静态扇(熵随 Δ 显著变化,极差 0.549 nats——头明显在用 Δ)。

**根因:分割几何的 patch 内熵周期。** 我们的"词核+尾随分隔符"分割使
Δ=1 永远是下一个 patch 的首字节 = 新词首字母(高熵——这正是 BLT 论文赖以
做熵分割的 word-start entropy concentration 现象),词内字节熵迅速走低。
H(Δ) 因此呈锯齿状,任何逐点单调判据必然误报。

## 2. v2 判据(三分量)

| 分量 | 测什么 | 合格标准 |
|---|---|---|
| **per-k 跨 patch 趋势** | 目标在第 k 个未来 patch 时的 acc/H | **acc 随 k 衰减(硬指标)**;真正的作弊检测——平坦或上升 = 头没有在做预测(静态扇同类),一票否决 |
| **per-Δ H 极差** | 头是否在用 Δ | 极差≈0(<0.05 nats)= 头忽视 Δ(v6 静态扇),一票否决 |
| **per-r patch 内剖面** | r=目标在 patch 内第几字节 | 预期 H 在 r=0 最高、词内走低(词首熵集中 = **H1 假设的直接测量**,不设否决线,作为观察项) |

诊断实现:`mtp_targets` 新增返回 k(patch 偏移)与 r(patch 内位置),
`scripts/diag_delta.py` 输出三张表 + 判据分解。

## 3. 首次实测(smoke ckpt,5.66M,仅 300 步,欠训练)

```
[2] per-k:  acc  0.1954 → 0.1404 → 0.0989   (k=1,2,3,严格单调衰减 ✓)
            H    3.051  → 3.046  → 3.043    (基本持平)
[1] per-Δ H 极差 = 0.549 nats               (头在用 Δ ✓)
[3] per-r:  H(r=0)=3.162 vs H(r>0) 均值 3.036,词首超额 +0.126 ✓
            acc(r=0)=0.054 → acc(r≥10)≈0.40-0.50
VERDICT: OK
```

三点解读:
1. **跨 patch 衰减在 300 步就已成形**——条件头确实在学习"越远的 patch 越难",
   静态扇作弊被排除,且这是欠训练模型,趋势只会随训练强化。
2. **per-r 的 acc 结构是 H1(词内长程确定性)的量化签名**:patch 首字节
   (新词首字母)最难(5.4%),词内越深越确定(40-50%)。
3. **per-k 的 H 基本持平而 acc 大降**:模型对"自己不知道远处"尚不自知
   (校准未跟上),列为 Stage 1 观察项——若规模化后 H 仍不随 k 上升,
   熵停止的 θ 标定需要按 k 分层处理。
