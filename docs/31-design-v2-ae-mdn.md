# 31 — v2 设计:字节串自编码器 + MDN 骨干(2026-09-17,用户拍板方向)

> 起因:用户裁决 **H1 不成立**——v1 的条件独立并行解码在原理上无法表示
> 多模态联合分布("cat/dog/dot" 问题),且使词级温度采样不可能,可能解释
> 收敛异常缓慢。新方向:吸收 CoSE(NeurIPS 2020,`reference_projects/
> cose_paper_full_text.txt`)的编解码器-骨干梯度分离设计,重构为
> **重建塑形的字节串嵌入 + 嵌入空间上的 GMM 自回归**。
> 本文是 v2 的设计文档;施工计划在 docs/32。**标 【待拍板】 的条目待用户
> 问询确认;审阅无误后才动工。**

## 1. 旧架构缺陷的判定(v1 病理分析)

**缺陷属实,且可精确归类**:这就是非自回归/并行解码的**条件独立病理**
(NAT multimodality 问题,D1 从第一天起就是风险登记册上最高的赌注)。

v1 的训练信号:对每个查询 `(h_j, Δ)` 独立做 CE。给定上下文 h,损失的最优解
是每个 Δ 位置上的**边际分布**;解码时各位置独立采样,等价于把联合分布
当作边际的乘积。用户的例子精确:在 "the most popular pet is _" 处,
"cat"/"dog" 各 50% 时,模型给出 Δ=1: c/d 各半,Δ=2: a/o 各半,Δ=3: t/g
各半——独立解码实质采样出 2^3=8 个组合,**"dot" 这样的幽灵词在原理上
无法被训练信号排除**,词表过滤也救不了(dot 是合法词)。

连带后果(全部已被自家诊断目击):
1. **表示层面的模式平均化**:h 被推往"各续写的均值嵌入",落在词模式之间
   ——这是用户所称的极坏归纳偏置;训练信号本身就在教混合表示。
2. **词级温度采样不可能**:字节独立升温 ≠ 词级升温,温度语义断裂。
3. **贪婪解码的吸引子/回声循环**(历次 gen 诊断:"the history of ... beg
   an wi the history of ..."):边际最大 + 无联合约束,自回归滚动时自我
   强化。
4. **word-first CE 全场最高**(mtp1 2.15,其余 2.9-3.0):词首正是分支点,
   混合病理在分支点咬得最狠。

**诚实的保留**:亏损底线(~2.50)与收敛缓慢是多因的(模型小、字节级任务
难、LR 史);模式混合税无法从现有日志干净剥离。v2 臂本身就是检验器:
若混合是主约束,AE+MDN 应在分支承诺度与生成多样性上立刻显出质变。

## 2. v2 架构总览

```
字节串 ──增强BPE分割──> patch 序列
patch_i ──Eθ(编码器)──> λ_i ∈ R^d_emb        ← 只受重建梯度
λ_1..λ_j(detached)──> Rθ(因果骨干)──> GMM(λ_{j+1})   ← 只受 MDN NLL 梯度
采样的 λ̂ ──Dθ(条件查询解码)──> 字节串(遇 EOS 止)
```

三个梯度区域:**Eθ/Dθ 只吃重建损失;Rθ 只吃预测 NLL,且 λ 输入 detach**。
(CoSE §3.3/§4.3 直接先例:全连接梯度流使 Recon CD 0.0136→0.0162、
Pred CD 0.0442→0.0470,解耦更好——我们的解耦是硬切断,比他们更彻底。)

### 2.1 分词:增强 BPE(取代词核规则分词)

- 每条样本算两套分割:① 规则预分词(space-like 分界的简易分词,自写,
  把串粗分为整词与符号);② Qwen3.5-2B 的 BPE tokenizer
  (权重在集群 `/gpfs1/scratch/yihe47/qwen35/models/Qwen3.5-2B`,
  **只需要 tokenizer 文件**,几 MB,可 scp 回本机)。
- 合成规则:对每个"至少一方主张切分"的字符间隙——双方一致 → 必切;
  只有一方 → 以概率 **p=0.5(已拍板,单一概率)** 随机切。产出整词/子词/
  单符号/多符号合并等多样模式,同时是对数学公式、连续符号序列鲁棒的方案。
- 随机化时机:**预烘焙(已拍板)**——缓存构建时每样本掷一次定型,只存
  一套分割。依据:本数据管线是**样本单遍训练**(10BT 缓存,2B run 全程
  仅用 26% 无重复),在线掷骰与预烘焙对模型等价,烘焙只费一次算力。
- l_max:混合 BPE 的 patch 可能长于 16(符号合并/长词),建议 **32**,
  Δ 查询域 1..32 + EOS 档。

### 2.2 字节串自编码器(Eθ/Dθ)

- **Eθ**:沿用 Set Transformer 骨架(byte 嵌入 + inducing 注意力池化),
  输出投影到 **d_emb=48 附近(S0 网格 {32,48,64}×{256,384} 定,从
  32-256 起跑——已拍板)**。**patch 内字节位置编码拼接保留**(d_byte
  384 + d_pos 64 拼接,v1 已有;用户 2026-09-17 提醒:无位置则 bag-of-bytes,
  顺序信息丢失)。宽度适度缩小(任务从"为预测服务"变成"紧凑重建",
  难度不同)。
- **Dθ**:条件查询解码 `(λ, Δ) → byte` 分布(复用 v1 条件头形态,film
  条件化),Δ ∈ {1..32}。**第 257 行 softmax = EOS 终止符**:所有字符串
  统一在末尾追加 EOS 目标(无论是否含 space-like 字节)——v1 的
  词界停止规则随之废止。
- **为何不用 CoSE 的归一化进度 t∈[0,1]**(用户裁决,记录):t 是连续量,
  整个进度有定义;字节串离散且推理时长度未知——等距进度采样无法控制
  间距,密集采样费算力且要分辨采样点间的未定义区域。EOS 终止符 +
  等距整数 Δ 是离散域的正确对应物。
- 训练:逐 patch 重建 CE(字节 + EOS);**无 KL/VAE**(CoSE Table 2:
  VAE 正则同时伤重建、预测与聚类质量——嵌入空间要的是"簇分明"不是
  "光滑";字符串本就是离散组合的,不需要插值行走)。
- 可选保险:**去噪解码,默认全关(奥卡姆剃刀,2026-09-17 拍板)**——
  分量内采样已定为只取 μ_k(见 §2.4),离流形风险下降。若实测鲁棒性
  不足再启用,且**优先字节腐化式**:encoder 输入端随机 drop 若干字节,
  decoder 输出端仍要求重建被丢字节——比 λ 上加高斯噪声更端到端;
  字节腐化也不够时才回 λ 噪声方案。
- **AdaLN 问询的落点(2026-09-17)**:用户问自适应层归一化有无参考价值——
  有,且已内化:v1 的 film 条件头(RMSNorm + 零初始化 scale/shift)正是
  adaLN-Zero 的近亲,v2 解码器沿用 film 条件化 λ;另借其零初始化思想
  给 **MDN 头输出层小初始化**,使初始 GMM 接近单一宽峰,稳定早期训练。
  它不构成嵌入空间约束的替代方案(那是 LayerNorm 的职责)。

### 2.3 骨干 Rθ + MDN 头

- 骨干本体**保持 768×12(~113M)不变**——隔离变量,它是 v1 里被验证
  的部分;RoPE 保留(文本有序,与 CoSE 的无序笔画集不同,位置编码必须留)。
- **输入适配器(2026-09-17 用户拍板,不设对照直接默认)**:不许线性直连
  48→768——那会把第一层输入的有效秩钉死在 ≤48,第一层 FFN 被迫充当
  适配器、白浪费一层注意力。改为**宽非线性升维再降维**:
  `LayerNorm → Linear(48→2048) → GELU → Linear(2048→768)`(中间维度
  > d_model;多模态投影的学界共识做法,MLP projector 优于 linear
  projector;几乎不可能引入有害偏置)。
- **MDN 头**:K=**64 【旋钮】** 分量,每分量 (π, μ∈R^d, σ∈R^d)——
  **对角协方差,不用全协方差**(2026-09-17 用户问询确认):σ 是逐维向量。
  分量只需圈住"一个确定字节串"的局部区域,跨维相关结构由多分量吸收
  (Graves 手写 MDN 与 CoSE 同为对角 σ)。
- **头与骨干之间垫两层非线性(2026-09-18 用户拍板,与输入适配器同理
  不设对照)**:输出目标不再是极高维无结构词表,而是有结构的 GMM 参数
  空间,直连一层线性太薄。结构:
  `h → Linear(768→1024) → SiLU → Linear(1024→1024) → SiLU →
  Linear(1024→K·(1+2d),小初始化)`(隐藏宽 1024 为旋钮)。
  参数量(d_model=768,K=64,含缓冲层):
  | d_emb | 输出维 K(1+2d) | 头总参数 | 占骨干 |
  |---|---|---|---|
  | 32 | 4,160 | ~6.1M | ~5.4% |
  | 48 | 6,208 | ~8.2M | ~7.3% |
  全协方差(Cholesky d(d+1)/2)在 d=32 就要 ~27.6M(~24%),d=48 ~60M
  (>50%)——不值。若日后对角欠拟合,中档选项是低秩+对角(r=4,d=32 约
  9.5M),Occam:先对角。π=softmax,σ=ELU+1+ε(下限防 σ→0 的 NLL 发散),
  输出层小初始化。NLL 在 fp32 下 logsumexp。spike_skip 守卫沿用。
- 训练:teacher forcing——输入 λ_1..λ_j(encoder 输出,**detach**),
  目标是真实 λ_{j+1} 在 GMM 下的 NLL。
- BOS:可学习起始嵌入(序列第一位)。

### 2.4 推理循环

1. BOS → Rθ → GMM 参数;按 **π 升温**(π^(1/τ) 归一)采分量 k;
2. **λ̂ = μ_k(已拍板:分量内只取均值,不采 σ 噪声)**——解码输入恒在
   分量中心,配合回投影几乎不离流形;
3. Dθ(λ̂, Δ=1,2,…) 逐档取 argmax/采样,直到 EOS → 一个字节串;
4. **回投影(建议默认开)**:把解码出的字节串重新过 Eθ 得到流形上的
   λ,作为下一步骨干输入——顶层状态永远是真实字符串,采样扰动不累积。
   【待拍板;留开关做消融】
5. patch 级停止 = EOS;文档级停止 POC 阶段固定生成长度,后续再议。
6. 温度语义终于成立:τ 直接作用于**分量权重**——一次采样 = 一个完整的
   词/子词承诺,词级温度采样由此可能。

### 2.5 与 CoSE 的对应与差异

| CoSE | v2 bltz | 备注 |
|---|---|---|
| 笔画(2D 点序列) | patch(字节串) | |
| t∈[0,1] 连续进度查询 | 离散 Δ + EOS | 用户裁决,§2.2 |
| Eθ transformer(带 PE) | Set Transformer 池化 | patch 内顺序由 byte 位置编码承担 |
| Dθ MLP([t,λ])→GMM | 条件查询头(film)→softmax | 输出离散分布而非点高斯 |
| Rθ 无位置(transformer 集) | 因果 transformer + RoPE | 文本有序,与图不同 |
| 位置预测 + 嵌入预测双因子 | 只有嵌入预测 | 文本无"落笔位置"自由度 |
| GMM K=10 足够(笔画) | K=64 起步 | 字符串模式数远多于笔画形状 |
| D=8(笔画) | d_emb=48 起步 | 字符串词表大;S0 网格定 |
| 梯度解耦(软,略好) | 梯度硬切断 | 同一动机的强化版 |
| VAE 有害(实证) | 不用 KL | 直接继承结论 |

## 3. 评估口径(跨架构可比)

- **字节级 CE**:预测分量(argmax π 的 μ)→ 解码 → 与真值算字节 CE 与
  exact-match 率——v1/v2 唯一公平的比较面都在字节层。
- **嵌入几何**:PR / anisotropy / kNN-CC 沿用,新增 **Silhouette
  Coefficient**(CoSE:SC 与预测质量 Pearson 相关 0.92,是嵌入空间质量的
  最佳单指标)。
- **承诺度/坍缩指标**:π 熵、val 上被实际使用的有效分量数、多次采样
  解码的字符串多样性(distinct-n)。
- 旧口径(gcos/edelta/demb 等)对 v2 部分失效(无 MTP 查询场),诊断
  套件对应改造,施工时落 docs/32 阶段。

## 4. 风险登记

| 风险 | 级别 | 缓解 |
|---|---|---|
| AE 嵌入空间质量是一票否决(骨干只能在它上面跳舞) | 高 | S0 本机先行;几何+重建双指标;CoSE D 消融先例 |
| MDN 训练不稳(σ 坍缩/NLL 尖峰) | 中 | σ 下限、fp32 logsumexp、spike_skip 沿用 |
| 采样 λ̂ 离流形 → 解码崩 | 中 | 去噪解码 + 回投影(§2.2/2.4) |
| frozen vs joint 动态微妙(CoSE 移植观察,用户标注:可信度低,仅作不收敛排查线索) | 中 | 两臂对照正是为此(S3) |
| 分割多样性引入训练噪声 | 低 | p 旋钮;在线/离线可选 |
| 收敛慢若多因,v2 不解决全部 | — | 诚实记录;v2 检验的是混合病理这一支 |

## 5. 决策记录

- **2026-09-17(用户裁决)**:H1 判不成立;v1 纯并行解码的条件独立病理
  属实;D4(跨 patch MTP)随 v2 一并废止(mtp1 实验是过渡证据:n=1 时
  近场效率 2.3×,已暗示深监督稀释);v2 方向(AE+MDN+增强BPE+EOS)
  拍板,先文档后动工。
- v1 全部 run/ckpt/文档存档不动;`boundary_2b` 主 run 暂停态保留(可续,
  是否续待 v2 首读后再议)。
- **2026-09-17 问询回填(用户答)**:① 分割随机化=**预烘焙**(单遍训练
  下在线/离线等价,烘焙省算力);② 分歧间隙 **p=0.5** 单一;③ 嵌入空间=
  **原始向量+骨干侧 LayerNorm**(AdaLN 问询→已内化于 film 解码与 MDN
  零初始化,见 §2.2);④ 分量内**只取 μ_k**;⑤ 双臂改为 **frozen 先行**,
  效果不佳再议 joint;⑥ S0 网格 6 组确认,**从 32-256 起跑**,patch 内
  位置拼接编码保留。
- 剩余待审阅项:回投影默认开(§2.4-4)、POC 步数(20k 先读)、l_max=32。
- **2026-09-17 审阅通过,补充两条(均直接默认,不设对照)**:① 骨干
  输入侧用宽非线性适配器(48→2048→GELU→768),不用线性直连(有效秩
  原理,见 §2.3);② 去噪解码维持默认全关,若需启用优先字节腐化式
  (输入丢字节、输出补全),高斯噪声为最后手段(见 §2.2)。
- **2026-09-17 深夜补充**:③ **64 维组弃跑**(用户经验判断:d=64 对 GMM
  过高——难点不在头参数(对角 σ 下 d=64 也仅 ~6M),在高维空间 GMM 的
  拟合几何);d_emb 候选收敛到 32/48。④ GMM 格式问询确认:**对角协方差**
  (参数表见 §2.3),全协方差不采用,低秩+对角留作后备。
