## 0. 现行设计全貌

### 0.1 设计原则(三支柱,经受住全部对照实验)

1. **重建塑形的冻结目标空间**:预测目标 λ 由重建训练的 AE 产生并冻结
   ——目标空间必须可解码、词形聚簇、稳定(词表吸附解码的地基)。
   梯度硬切断:重建梯度不进骨干,预测梯度不进 AE。
2. **密度拟合而非逐词分类**:骨干用 MDN/GMM 拟合 λ 的条件密度。**分量
   是密度基函数**(多分量合作叠峰,模式可不在任何 μ_k 上),不是词
   (2026-09-28 修正,详见 §1-6)。
3. **密度泛函读出**:解码只走 snap(词表密度吸附)/ mode(GMM MAP);
   词级温度/top-k 成立于表分布。

### 0.2 数据流

```
原文本 --word臂切词(确定性)--> 单位(B,S,L<=32 bytes)
  ├─ [冻结 AE encoder] -> λ(48) ──detach──> MDN 目标(逐位置)
  └─ [输入路径 A 冻结]:AE encoder(同上)->LN+MLP adapter->骨干   [默认]
     [输入路径 B 可学习 Beta]:ByteLayerEncoder->骨干(同结构对照待做)
骨干 768x12(pre-norm RMSNorm/RoPE/SwiGLU) -> h
MDN 头(纯线性):h -> K(1+2d)=6208 -> {logit π, μ, σ}  [K=64,d=48]
训练:GMM NLL(fp32 logsumexp;σ=elu+1+σ_floor,σ_floor=0.05)
读出:snap: argmax_n Σ_k π_k N(V_n; μ_k, σ_k)(词表 V=Qwen∪cache-top)
      mode: argmax_x Σ_k π_k N(x; μ_k, σ_k)(均值漂移定点迭代)
生成:每步取 mode/snap 向量(流形点)→ 嵌入反馈(UNSHIFTED 前缀)
```

### 0.3 切词规格(word 臂,现行主轴;segment_word)

Unicode 词/数/符三分类;字母段=整词、符号段=纯净分隔符、**数字独立成
patch**;**恰好一个空格并入前一 patch(除非前一是数字)**——'Stock ' 与
[' , ', ': ', '? ']同构(尾随空格语义);超 32B 段 BPE 兜底;完全确定性。
消融对照臂 = 纯 BPE(Qwen 边界,零随机;bpb 已证更优 ~15%,持续跟踪)。

### 0.4 AE 现行配方

48-256(宽 256/layers 2/heads 4/d_emb 48);编码器 ISAB 或**标准自注意力
(inducing=0,长训版)**;PMA 池化;解码 FiLM(λ,Δ)→257(EOS 行 256),
dec_hidden 384;typo 增强 p=0.05(长训)/0.1(word 基线),忠实重建口径;
训练 cosine 4e-4→4e-6,fp16+GradScaler+守卫,断点续训。

## 2. 设计决策史(起草稿拍板记录,存档)

- 梯度硬切断(CoSE 3.3 式,硬化):AE 只吃重建梯度,骨干只吃 NLL;
- 预烘焙分割拍板(单遍训练与在线等价);
- AdaLN 思路内化 FiLM(解码器)与 MDN 小初始化(零 bias,初始单宽高斯);
- 分量均值采样(τ 只调 π)——**已被密度泛函读出取代(§1-6/7)**;
- frozen 输入先行,joint 降级备选(§1-9 的 Beta 即其审慎后继);
- 保留 patch 内位置拼接编码(byte+pos concat,顺序必须可见);
- EOS=softmax 第 257 行,取代 v1 词界停止;
- 对角协方差(全协方差高维否决,低秩后备未启用);
- 宽适配器 LN→48→2048→GELU→768(§1-11 的对照开关为其补测);
- K=64 不变(K=16 证伪"梯度稀疏"假说);
- 三支柱原则(§0.1)中第 2/3 条于 09-28 由用户洞察定稿。
