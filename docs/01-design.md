## 2. 问题定义(继承 MoB_Head)

固定词表 LM 的结构性代价:128K×h 的 unembedding 每步解码要读 501 MiB(Llama-3.2-1B);tokenizer 是训练前定死的压缩启发式,带来领域敏感、噪声脆弱、多语言不公平、正字法知识缺失。MoB_Head 用二进制码头替代 unembedding 验证了"输出侧去词表"的价值;本项目走向彻底的**词表 free**:输入输出两侧都是字节,词汇表就是 256 个字节。

字节级建模的能力证据已充分:BLT(arXiv:2412.09871)在 8B/4T 字节上 FLOPs 受控追平 Llama-3,CUTE 字符任务大幅超越(54.1 vs 27.5);Grapheme-LLaMA(arXiv:2410.01487,BabyLM)15M 字符模型逼近 58M 子词模型,词汇判断任务 99% vs 69%;MambaByte(2401.13660)、EvaByte(HKU 2025,6.5B/1.5T 字节)、H-Net(2507.07955)等持续刷新证据;字符级小模型生态活跃(如 Bunzeck 的 lexdec 系列,huggingface.co/bbunzeck/lexdec-medium-char,用户指示)。

**本项目的独有问题**:BLT 证明了"字节级可行",但留下了两个疙瘩——(a) 逐字节自回归的局部解码器(1B 规模下 9 层 113M)仍是推理瓶颈,Fast BLT(2605.08044)整篇都在给它打补丁(扩散/自投机/验证);(b) 输入侧分割与输出侧生成都依赖一个**外部熵模型全程在环**(官方代码 `realtime_patching=True`)。我们要把这两个疙瘩同时消掉。

## 3. 核心假设(可证伪,每个都有对应诊断)

- **H1 词内长程确定性支撑纯并行边际解码。** 词内字节的条件分布接近确定,多样性集中在词边界;Medusa 在 token 级被诟病的"违反 token 间因果"在字节级大幅减弱。证据:BLT-S 自投机的字节接受率 k=4 时 95~99%、k=8 时 86~96%(Fast BLT 表 3-6);BLT 熵图中熵集中在词首。风险:多峰未来的边际混合(cats/dogs → cags),由熵停止 + 诊断 D-1/D-7 暴露。
- **H2 patch 先验加权的 MTP 训练使 h 成为"未来一段变长序列的语义流形编码"。** 条件头 `(h, Δ) → byte` 强制 h 把未来 n 个 patch 的可预测部分编码成可按 Δ 查询的连续场。
- **H3 深而条件化的单头吸收多目标梯度冲突。** 不同 Δ 的梯度经 Δ 条件通路分流,不直接拉扯 h;对照证据:AdaMTP(2608.00434)实测固定视野 MTP 准确率随头数单调恶化(跨语义边界的冲突梯度),OCC(2605.28184)把联合 MTP 的损害分解为一阶相关项+恒负二阶项。诊断 D-3 直接测量本架构的梯度余弦。
- **H4 模型自身熵停止可替代外部熵模型在线分割。** 即 BLT 论文自点的 future work("learning the patching model end-to-end"),H-Net 的输入侧类比已验证可行;我们做输出侧。
- **H5(开放实验问题)语义固定分割 vs 熵分割。** 同等地位消融,不预设论文先验(D3)。

## 4. 总体架构

```
字节流 (训练文本 / 推理 prompt)
  │
  ▼
[分割器]  确定性语义分割(训练/预填充共用;熵分割为消融臂)
  │  patch 序列 p_1..p_M(变长,≤ L_max 字节)
  ▼
[Set Transformer 编码器]  逐 patch:字节嵌入 ⊕ 局部位置编码 → ISAB×L_e → PMA → patch latent
  │  p_j ∈ R^d_model
  ▼
[骨干 transformer]  Llama 式 patch 级自回归(causal,文档边界 block-causal)
  │  h_j = G(p_≤j)
  ▼
[条件解码头]  (h_j, Δ) → 256-way softmax,预测 patch j 之后第 Δ 个字节
  │
  ▼ 推理循环
  熵停止 → 提交字节段 → 回编码器聚成新 patch → 骨干 → …
```

与 simple_point_cloud 的对应:Set Transformer 编码器 ↔ 其空间编码器(只看单帧);
骨干 ↔ 其因果时序编码器;条件头 `(h, Δ)` ↔ 其 v6b 未来预测 `(emb_j, dt)`。

## 5. 模块规格

### 5.1 分割器(固定语义分割 v1,D3)

设计意图(用户):**固定下来的只有"切词"能力**——把单词按字节切成子词级语义小块;
合并与符号归附按下面的明确规则。目标:每个 patch 是"大致语义完备"的单元(完整子词,
或带词尾空格/标点的词),使骨干要建模的 patch 模式空间可控。

**算法(确定性基底)**:

1. **词核切分**:对解码后的字符串做正则切分,词核 = 字母/数字的最长 run,或单个
   CJK 字符,或单个其他非分隔符字符;英文缩写 `'s/'t/'re` 等归附前一个词核。
2. **尾随归附**:词核之后的所有连续分隔符(空格/标点 run)归附到该词核所在单元
   → base unit = "词核 + 尾分隔符"。例:`"Hello, world!"` → `["Hello, ", "world!"]`;
   `"你好,世界"` → `["你", "好,", "世", "界"]`。
3. **超长细分**:unit 字节数 > `L_max` **[提议 16]** 时,在 UTF-8 字符边界内等分切成
   ≤ L_max 的块(刻意不用 BPE 回退表——保持零依赖,检验架构真实能力)。
4. **UTF-8 保护**:任何切分不得落在多字节字符中间(切分在 str 上做,映回字节)。

**随机双增强(仅训练集,每个 epoch 重采样;验证/评估永远用确定性基底)**:

5. **随机细分** `p_split` **[提议 0.1]**:以该概率在某 unit 的随机合法边界再切一刀。
6. **随机拼接** `p_merge` **[提议 0.1]**:以该概率把相邻短单元合并(总长 ≤ L_max),
   优先作用于短单元。

随机增强的功能定位(一等公民,不是普通数据增强):推理时熵停止可能切在非语义边界
(半个词),这些"残缺 patch"对编码器是 OOD;双增强让 Set Transformer 在训练中见过
任意合法字节子段,弥合"训练分割受控 / 推理分割自由"的分布缺口。

**输出**:每篇文档 = 字节数组 + patch 起始掩码,落盘缓存(`data/`)。

### 5.2 Set Transformer 编码器(D2, D8)

- 输入:一个 patch 的字节序列(≤ L_max)。
- 每字节:byte embedding(256 × `d_b` **[提议 384]**) ⊕ 拼接局部位置编码
  (patch 内序号 0..L_max−1 的**学习式**嵌入,`d_p` **[提议 64]**)→ Linear 到 `d_enc`。
- L_e 个 ISAB(inducing points `m` **[提议 16]**,heads 8)→ **PMA(k=1)** 池化成单个
  patch latent(D8;mean pooling 为消融臂)→ Linear 投影到骨干 `d_model`。
- 提议规模:`d_enc=512, L_e=2`(~16M 参数:2×ISAB 12.6M + PMA 3.2M + 投影;
  BLT 局部编码器为 12M,Fast BLT 为 19M,同量级)。**[待拍板]**
- 正确性论证(无泄漏):编码器只看已提交/已有的 patch 字节,patch 内字节互相可见
  是允许的——它们整体构成"输入";patch j+1 的字节对编码 patch j 不可见。

### 5.3 骨干 transformer

- Llama 式 decoder-only over patch latents:RMSNorm、RoPE(θ=500000)、SwiGLU;
  causal;文档间 block-causal(packing 时不跨文档)。
- 输入投影:patch latent → d_model;无词表嵌入表(整个模型没有大 embedding 层)。
- 尺寸:**twin 124M 级 `d=768, L=12`**(~110M 非嵌入);**1B 概念验证 `d=2048, L=25`**
  (对齐 BLT-1B global 的 1B 参数)。**[待拍板]**

### 5.4 条件解码头(D1)

- 输入:`[h_j; emb(Δ)]`,Δ ∈ [1, K_max],**K_max = n × L_max**;`emb(Δ)` 为学习式嵌入
  (dim 64 **[提议]**)。**Δ 永远是相对偏移,绝不喂绝对位置**(v6 静态扇教训,
  见 simple_point_cloud EXPERIMENT_LOG §8-9)。
- 结构:SiLU MLP,**[提议]** twin 规模 4 层 × 宽 1536(~20M);1B 规模 6 层 × 宽 3072
  (~110M,对齐 BLT 局部解码器 113M 的量级——把原来局部解码器的预算整个搬进条件头)。
- 输出:Linear → 256 logits。不与编码器 byte embedding  tying(v1 简单起见)。
- 关键实现事实:给定 h,所有 Δ 查询相互独立 → 推理时一次 batched 前向即可拿到
  Δ=1..m_max 的全部分布,头开销极小。

## 6. 训练目标(D4)

对每个 patch 位置 j(文档内,packing 不跨文档):

```
K_j = len(p_{j+1}) + … + len(p_{j+n})          # 覆盖未来 n 个 patch(文档尾截断)
L = Σ_j Σ_{Δ=1..K_j} w(Δ) · CE( head(h_j, Δ), byte_{end(p_j)+Δ} ) / Σ_j Σ_Δ w(Δ)
w(Δ) = λ^(k(Δ)−1),  k(Δ) = Δ 所落在的未来第几个 patch
```

**[提议] n=3, λ=0.5**(第 1 个 patch 权重 1.0,第 2 个 0.5,第 3 个 0.25;n 与 λ 进消融)。
设计语义(用户):利用 patch 先验确定"哪些字节应稳拿(第 1 patch),哪些不强求(远端)";
与 Gumiho(2503.10135)"早期 draft token 更重要"的发现一致。

- 无其他辅助损失:无 patch latent 回归、无独立 next-byte AR 损失——h 的全部梯度
  来自条件头(H2 的纯粹性;BLT-D 保留 L_clean 是因为它有局部 AR 解码器,我们没有)。
- 优化器:AdamW(β1=0.9, **β2=0.95**, eps=1e-8, wd 0.1, clip 1.0);
  LR 调度 **WSD**(house rule:可续训 run 默认 WSD),peak 参考 BLT 的 4e−4 **[待拍板]**;
  spike guard = max(10×running median, 2000)(simple_point_cloud 纪律)。

## 7. 推理循环(D1, D5)

```
prefill:  prompt → 确定性分割 → 编码器 → 骨干 → h_M
loop:
  1. 头对 h 做一次 batched 前向:Δ=1..m_max 的 256-way 分布与逐 Δ 熵 H(Δ)
  2. Δ* = 首个 H(Δ) > θ_stop 的位置;无则 Δ* = m_max+1
  3. 提交字节 1 .. max(Δ*−1, 1)        # 至少提交 1 字节,保证进展(防死循环)
     (贪心或采样取值,逐位置独立)
  4. 提交字节段 → 编码器 → patch p_{M+1} → 骨干(KV cache) → h_{M+1}
```

- **θ_stop 是速度/质量旋钮**:θ_stop→0 退化为逐字节 AR(每步只提交 1 字节,最稳);
  θ_stop→∞ 退化为固定 m_max 投机(最快)。中间值让模型在易预测段自动加速——
  类比 BLT 推理期把熵阈值 0.6 调到 0.1 的 lever,但我们是输出侧原生支持。
- **m_max [提议 = L_max = 16]**:保证回喂给编码器的 patch 长度永远在训练分布内。
- 采样语义:边际解码下逐 Δ 独立采样;低熵段边际≈联合(H1),高熵处本来就会停。

## 8. 效率核算(诚实版)

每提交一个字节的成本 ≈ `1/m_stop` 次骨干前向 + 编码器/头的微小开销(头一次
batched 前向摊到 m_stop 个字节上)。token LM ≈ 每 4.4 字节一次前向。

**NFE 持平不是胜利**:m_stop≈5 时骨干 NFE/字节与 token LM 相当。真正的收益在:
(a) 输出侧带宽——256-way softmax vs 128K-way unembedding(MoB_Head 的核心动机,
每步权重读取从 ~500 MiB 降到 KB 级);(b) 自适应粒度——公式化/重复文本上 m_stop
自动走高(BLT 的熵图证据),token LM 无法做到这一点;(c) 无词表的全部衍生好处
(鲁棒性、字符感知、多语言公平)。(d) 输入侧分割只在 prefill 跑一次,生成段的分割
由模型自身熵决定,无第二个模型常驻——对比官方 BLT 推理需熵模型全程在环。

## 10. 与先行工作的区隔(写作时须正面引用)

- **vs BLT (2412.09871)**:我们删掉局部 AR 解码器(其 1B 规模 9 层 113M)与推理期
  熵模型在环;编码器从"窗 512 字节 transformer + hash n-gram + cross-attn 池化"换成
  单 patch Set Transformer;输出侧分割由模型自身熵决定。
- **vs Fast BLT (2605.08044)**:BLT-D/S/DV 都在给局部解码器加速(扩散/自投机/验证),
  我们直接删除局部解码器;他们的 block diffusion 跨 patch 预测未来字节与我们
  MTP 视野跨 patch 同构,但我们用显式 Δ 查询 + 熵停止而非掩码扩散。
- **vs AdaMTP (2608.00434,最近邻)**:token 级、多头、用外部熵信号做掩码与停止;
  我们:字节级、单条件头、patch 先验几何衰减、模型自身熵停止、分割策略消融。
  其"跨语义边界的 MTP 梯度有害"证据是我们 D4 加权设计的直接动机。
- **vs Medusa-2 (2401.10774)**:联合训练不稳定靠 warmup/自蒸馏缓解(backbone 已预训);
  我们从零训练 + 条件头吸收冲突(H3),无需蒸馏教师。
- **vs H-Net (2507.07955) / MrT5 (2410.20771)**:端到端学习分割(输入侧);我们输入侧
  用显式受控分割(D3 的设计公理),输出侧模型自定界(H4)。
- **vs Perceiver IO (2107.14795)**:query 位置编码从 latent 解码输出的灵感来源;
  他们是 masked byte MLM(非自回归)。
- **Gloeckle et al. 2024 (2404.19737)**:从零训练的 token 级并行 MTP 在大规模稳定有效
  (n=4 最佳)——支持"从头训练时 MTP 不稳定可控"的一面,与 AdaMTP 证据互为边界。
